# Jewellery workshop site, 6 pages

A quiet site of a jeweller with collections, a product page where the metal changes the price and the ring, and a ring builder with a live preview.

**Live:** https://dmitrii-mazurkevich.github.io/jewellery-workshop-website/

![Jewellery workshop site, 6 pages](preview.png)

## Built with

HTML, CSS, JavaScript, SVG, localStorage. Static site without a build step: open `index.html` or publish the folder to any hosting.
English and Russian versions with a language switcher, layout for phones and desktops.
